Configuración de Cloudinary

Configura tu cuenta de Cloudinary para subir fotos. Los datos EXIF se leen automáticamente de la foto.

Borrar fotos de Cloudinary (opcional)

Cloudinary exige una firma para borrar. Pega tu API Key y API Secret (Dashboard → API Keys). Se guardan solo en este navegador, nunca en el archivo. Úsalo únicamente en tus dispositivos personales.

¿Cómo obtengo estos datos?
  1. Entra a cloudinary.com y crea una cuenta gratuita.
  2. En el Dashboard copia tu Cloud Name.
  3. Ve a Settings → Upload → Upload presets → Add upload preset.
  4. En Signing mode elige Unsigned y guarda.
  5. Copia el nombre exacto del preset y pégalo arriba.
  6. Los datos EXIF se leen en tu navegador antes de subir la foto.
